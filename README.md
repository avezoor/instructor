## What's in here

Each file is a ready-to-paste instruction set for configuring LLM behavior
in a specific academic context. Drop any `.md` file into:

- Claude → Projects → Project Instructions
- ChatGPT → Custom Instructions / System Prompt
- API → `system` parameter

## Tools

| Tools | Placement | Limit |
|-------|-----------|-------|
| [`ChatGPT`](ChatGPT) | Custom Instructions | 1500 characters |
| `Claude` | Project Instructions | No hard limit |
| `API` | `system` parameter | Model context window |

## Design Principles

- No apologies, no filler — critical and direct by default
- LaTeX-enforced mathematical notation
- Mandatory citations: Q1/Q2 Scopus, IEEE, ACM, CVPR, NeurIPS, ICML
- SOTA benchmarking with historical context
- Indonesian research context awareness
